CSS POSITIONING DETAILS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Parent (Link):
  className="... relative"
  └─ Creates positioning context for absolute children

Active Indicator:
  className="absolute bottom-0 left-1/2 -translate-x-1/2 w-6 h-1 rounded-t-full bg-gold"
  
  Breakdown:
    • absolute      → Positioned relative to parent (Link)
    • bottom-0      → Pinned to bottom edge
    • left-1/2      → Move to center (50% from left)
    • -translate-x-1/2 → Shift left by half of element width (center it)
    • w-6           → Width: 24px (spans icon area)
    • h-1           → Height: 4px (thin bar)
    • rounded-t-full → Top corners rounded for smooth appearance
    • bg-gold       → Gold color (#d4a960)

Result:
  ┌─────────────┐
  │      ●      │  ← Icon (centered)
  │  Label Text │
  │  ━━━━━━━━━  │  ← Gold bar (bottom-0, centered)
  └─────────────┘
