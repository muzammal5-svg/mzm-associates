================================================================================
LANDING PAGE UI ISSUES - ANALYSIS & FIXES
================================================================================

SCREENSHOT ANALYSIS: Multiple overlapping UI elements, z-index conflicts, 
responsive layout breakage on mobile/tablet screens.

================================================================================
ISSUES IDENTIFIED (6 Total)
================================================================================

1. 🔴 OVERLAPPING TEXT & CONTENT
   - Hero section copy overlays dashboard mockup
   - "Streamline Your Law Practice" text flows into buttons/images
   - Root Cause: md:grid-cols-2 with insufficient gap; no z-index
   
2. 🔴 LANGUAGE SWITCHER MISALIGNMENT
   - Language pills (EN/UR) appear misaligned in header
   - Root Cause: Absolute positioning without proper container

3. 🔴 HEADER Z-INDEX CONFLICTS
   - Sticky header (z-50) creates stacking context problems
   - Hero section appears behind header
   - Root Cause: z-50 too high; conflicts with mobile drawer

4. 🟡 BUTTON ALIGNMENT & SIZING
   - CTA buttons overlap or misalign on smaller screens
   - "Start free trial" and "View pricing" buttons stack incorrectly
   - Root Cause: Fixed gap-3; no mobile-specific widths

5. 🟡 HERO SECTION RESPONSIVENESS
   - Layout breaks on tablet/mobile
   - Text flows into dashboard mockup area
   - Root Cause: md:grid-cols-2 applies too early; needs lg:

6. 🟡 MOBILE DRAWER OVERLAY
   - Backdrop too opaque (solid black)
   - Mobile menu appears jarring
   - Root Cause: Inline style backgroundColor: '#000000' with no alpha

================================================================================
SOLUTIONS IMPLEMENTED
================================================================================

FILE 1: web/components/marketing/Landing.tsx

FIX 1A: Hero Grid Layout
  OLD: md:grid-cols-2 md:gap-10 py-16
  NEW: lg:grid-cols-2 lg:gap-16 py-12 md:py-20
  
  Why: Keeps single column on mobile/tablet; splits on lg+ (1024px+)
       Responsive padding and gap for better spacing

FIX 1B: Hero Copy Container  
  OLD: <div className="text-center md:text-start">
  NEW: <div className="z-10 flex flex-col items-center text-center md:items-start md:text-start">
  
  Why: Explicit flex layout; z-10 ensures text stays above blur element
  
FIX 1C: Responsive Heading Sizes
  OLD: text-[34px] md:text-[52px]  (only 2 sizes)
  NEW: text-[2rem] sm:text-[2.5rem] md:text-[3rem] lg:text-[3.25rem]  (4 sizes)
  
  Why: Better scaling across breakpoints (320→640→1024→1280px)

FIX 1D: Button Container (Mobile → Desktop)
  OLD: <div className="mt-9 flex flex-wrap gap-3 md:justify-start">
       - Buttons wrap awkwardly on mobile
  
  NEW: <div className="mt-8 flex flex-col gap-3 sm:flex-row sm:justify-center md:justify-start">
       <Link className="h-12 w-full sm:w-auto">
       - Full-width on mobile, side-by-side on sm+
       
  Why: Better touch targets (48px height), stacked UX on mobile

FIX 1E: Dashboard Mockup (Hide on Mobile/Tablet)
  OLD: <div className="relative"><HeroDashboard /></div>
       - Always shown, causes overlap
  
  NEW: <div className="relative z-5 hidden lg:block"><HeroDashboard /></div>
       - Hidden until lg breakpoint (1024px+)
       
  Why: Dashboard doesn't fit mobile/tablet screens; prevents overlap

================================================================================

FILE 2: web/components/marketing/PublicHeader.tsx

FIX 2A: Header Z-Index & Opacity
  OLD: z-50 bg-slate-900/90 backdrop-blur-lg bg-slate-900/75
  NEW: z-40 bg-slate-900/95 backdrop-blur-xl bg-slate-900/80
  
  Why: z-40 is lower than modals/drawers (z-50); prevents overlap
       Higher opacity (95%) for better readability
       Stronger blur (xl) for modern glass effect

FIX 2B: Mobile Drawer Backdrop
  OLD: className="bg-black" style={{ backgroundColor: '#000000' }}
       - Opaque black, jarring overlay
  
  NEW: className="bg-black/60"
       - 60% opacity, semi-transparent
       
  Why: More polished mobile menu experience; see content behind
