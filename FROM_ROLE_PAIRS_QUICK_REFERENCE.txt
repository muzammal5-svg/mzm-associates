IMPLEMENTATION DETAILS
─────────────────────────────────────────────────────────────────────────────

CENTRALIZED MAPPING (web/lib/caseTypeConfig.ts):
  
  FROM_ROLE_PAIR_MAP = {
    "Plaintiff": { primaryEn: "Plaintiff", primaryUr: "مدعی", 
                   secondaryEn: "Defendant", secondaryUr: "مدعا علیہ" },
    "Defendant": { primaryEn: "Defendant", primaryUr: "مدعا علیہ", 
                   secondaryEn: "Plaintiff", secondaryUr: "مدعی" },
    ... (12 total pairs)
  }

HELPER FUNCTION:
  
  getPartyPairForFromRole(fromRole) → Returns FromRolePair
  - Looks up FROM role in FROM_ROLE_PAIR_MAP
  - Returns primary + secondary labels
  - Fallback for unknown roles

FORM UPDATE (web/app/cases/new/page.tsx):

  const currentFrom = watch("From");
  const displayPartyConfig = {
    primaryEn: getPartyPairForFromRole(currentFrom).primaryEn,
    secondaryEn: getPartyPairForFromRole(currentFrom).secondaryEn,
    // ... other properties
  };

  <Input label={displayPartyConfig.primaryEn} ... />
  <Input label={displayPartyConfig.secondaryEn} ... />
